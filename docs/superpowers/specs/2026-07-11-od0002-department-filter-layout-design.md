# OD0002 部门筛选与查询区布局设计

## 目标

为 OD0002 门店销售毛利汇总表增加单选部门筛选，移除重置按钮，并将查询条件区调整为“统计期间 + 组织范围”的双区布局。

## 部门筛选规则

- 部门为单选下拉框，默认选项为“全部部门”。
- 选择“全部部门”时，查看当前门店条件及用户数据权限范围内的全部部门。
- 选择具体部门时，报表仅统计该部门。
- 门店为“权限内全部门店”时，部门下拉列出所有权限门店内可见部门。
- 选择具体门店后，部门下拉只列出该门店内可见部门。
- 门店变化时，部门自动恢复为“全部部门”，避免保留不属于新门店的选择。
- 部门选项及报表数据均沿用现有允许/拒绝数据权限过滤。
- 部门选项复用销售看板的 `department_display_sort_key` 排序。

## 数据与接口

- OD0002 提供专用的权限过滤部门选项接口，接受可选门店编码。
- OD0002 查询与 Excel 导出接口增加可选部门编码参数。
- 部门条件在 OD0002 基础数据集聚合前生效，因此六个维度、合计、质量提示和 Excel 导出使用同一数据范围。
- 未选择具体部门时不传部门参数，保持现有全部部门行为。

## 查询区布局

采用 B 型分组双区布局：

- 左侧“统计期间”：本期开始、本期结束、自动同期开始、自动同期结束，以两列网格排列。
- 右侧“组织范围”：门店、部门并排排列。
- 查询和导出 Excel 按钮放在组织范围区域右下方。
- 删除重置按钮及其事件逻辑。
- 中等宽度下两个区域上下排列；移动端控件按单列排列。
- 保留日期校验、加载状态和导出错误提示。
