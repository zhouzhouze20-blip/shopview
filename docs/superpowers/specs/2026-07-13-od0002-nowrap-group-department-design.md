# OD0002层级名称不折行与柜组部门设计

## 目标

完善“OD0002 门店销售毛利汇总表”的两个展示细节：

1. 在线“部门（含品类）”页签中的门店、部门、区域、品类固定采用“名称一行、编码一行”，名称本身不再自动折行；
2. 现有“柜组”维度补充所属部门，并同步到在线页签和 Excel“柜组”工作表。

本次不新增页签或工作表，不改变销售收入、毛利额、毛利率、同期、同比、筛选和权限口径。

## 在线层级名称固定两行

“部门（含品类）”页签的四个层级单元格继续显示：

```text
完整名称
编码
```

名称行和编码行都应用不换行样式。名称如“欧美进口品”必须完整显示在第一行，不能拆成“欧美进口”与“品”两行。编码 `0101` 单独显示在第二行。

门店、部门、区域、品类列设置合理的最小宽度；内容超过当前视口时由表格容器横向滚动，不通过压缩列宽或拆分名称适配。区域小计、部门小计也遵循相同规则。

其他维度当前“名称 + 编码”的两行展示同步复用同一不折行单元格组件，避免“柜组”新增部门列后再次出现名称拆行。

## 柜组数据粒度

后端 `groups` 维度从当前粒度：

```text
门店编码 + 柜组编码
```

调整为：

```text
门店编码 + 部门编码 + 柜组编码
```

`groups` 聚合结果保留：

- `store_code`、`store_name`；
- `department_code`、`department_name`；
- `dimension_code`、`dimension_name`，继续表示柜组编码和柜组名称；
- 原有九个销售收入、毛利额、毛利率指标。

部门仍来自柜组上级 `manaframe` 记录。聚合使用 OD0002 已有的权限过滤后 `base` 数据，不另建事实查询，也不根据柜组编码前缀推断部门。

同一门店中即使出现柜组编码重复，只要所属部门不同，就必须作为两条柜组结果返回。用户选择部门筛选时，柜组页签和 Excel 只包含所选部门范围。

## 在线“柜组”页签

在线“柜组”页签的标识列调整为：

- 查询“权限内全部门店”时：门店、部门、柜组；
- 查询单门店时：部门、柜组。

部门和柜组均使用“完整名称一行、编码一行”的不折行组件。表头中的原“维度”改为明确的“柜组”。

九个指标列、同比颜色、万元和百分比格式、分页、加载状态、空数据状态、合计行保持不变。合计行只汇总柜组明细，增加的部门列为空，不产生额外部门小计。

其他六个页签的列结构保持不变。

## Excel“柜组”工作表

Excel“柜组”工作表不再使用四个标识列的通用写入器，改用柜组专用写入器。标识列顺序固定为：

1. 门店编码；
2. 门店名称；
3. 部门编码；
4. 部门名称；
5. 柜组编码；
6. 柜组名称。

后接原有九个指标列，因此工作表总列数由十三列变为十五列。标题和日期行合并到 `O` 列；指标分组从 `G` 列开始。冻结位置仍为 `A8`。

部门编码、部门名称、柜组编码、柜组名称均作为文本值写入，继续防护以 `=`, `+`, `-`, `@` 开头的内容，避免公式注入。金额和百分比保持数值类型及现有格式，合计行只写一次。

其他工作表，包括“部门（含品类）”，保持现有结构和顺序。

## 数据流与复用边界

在线查询和 Excel 导出继续调用同一个 OD0002 报表服务。后端只扩展 `groups` 行的结构字段；页面和 Excel 不执行部门关联，也不重新汇总销售金额。

现有 `Od0002Row` 的可选 `department_code`、`department_name` 字段直接用于柜组行，无需新增第二种柜组响应类型。

## 空值与异常处理

- 柜组有名称但无法关联部门：保留柜组行，部门显示“未匹配”，不能丢弃销售金额；
- 部门编码为空：页面编码位置显示破折号，Excel 部门编码保留为空；
- 同期值为零：继续显示空同比；
- 无柜组数据：页面显示标准空状态，Excel“柜组”仍包含完整十五列表头和合计行；
- 导出失败：沿用现有提示，不生成空文件。

## 测试策略

后端测试覆盖：

- `groups` CTE 选择并按部门编码、名称分组；
- 相同门店和柜组编码位于不同部门时不合并；
- `normalize_rows` 在柜组行保留部门编码和名称；
- 门店、部门和柜组权限过滤仍在公共 `base` 数据集生效；
- 柜组合计保持原有指标口径。

前端测试覆盖：

- 层级名称和编码使用不折行样式；
- “欧美进口品”一类名称不会被拆行；
- “柜组”页签展示部门和柜组两列；
- 多门店时仍展示门店列，单门店时隐藏门店列；
- 合计行、分页和其他页签保持兼容。

Excel 测试覆盖：

- “柜组”工作表为十五列；
- 部门编码、部门名称位于柜组编码、名称之前；
- 标题合并范围、表头、冻结窗格、金额及百分比格式正确；
- 公式型部门和柜组文本被转义；
- 空数据仍生成有效表头和合计；
- 其他工作表结构不变。

## 验收方式

1. 在“部门（含品类）”页签确认“欧美进口品”完整显示在第一行、编码在第二行；
2. 在“柜组”页签确认每行显示所属部门和柜组；
3. 选择单个部门后，柜组页签只保留该部门柜组；
4. 导出 Excel，确认“柜组”工作表包含部门编码和部门名称；
5. 在线柜组合计与 Excel 柜组合计一致；
6. 多门店查询时，同一柜组编码在不同部门或门店下不会合并。

## 不在本次范围内

- 新增“柜组（含部门）”页签或工作表；
- 给“柜组”增加区域或品类列；
- 在柜组页签增加部门小计；
- 修改原有指标、日期、权限和筛选条件；
- 改变其他 Excel 工作表的列结构。
