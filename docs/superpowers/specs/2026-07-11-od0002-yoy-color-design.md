# OD0002 同比颜色设计

## 目标

OD0002 门店销售毛利汇总表采用中国财务报表常用颜色习惯：同比上升显示红色，同比下降显示绿色。

## 范围

- 仅作用于销售收入、毛利、毛利率三个“同比”单元格。
- 明细行和合计行使用同一规则。
- 本期、同期数值不参与同比颜色判断。

## 显示规则

- 同比值大于 `0`：`text-red-600`。
- 同比值小于 `0`：`text-green-600`。
- 同比值等于 `0` 或无法计算：保持默认文字颜色。

颜色根据原始数值判断，不根据格式化后的字符串判断，避免舍入和非同比负数造成误判。

## 实现与验证

在 OD0002 前端报表逻辑中提供同比颜色映射，并在渲染三个同比列时调用。测试覆盖正数、负数、零值，并检查明细与合计渲染都使用同一规则。完成后运行 OD0002 前端测试与 TypeScript 类型检查。
