# 自营公司销售与手工导入

电脑端入口：销售管理 → 自营销售导入。
手机端入口：销售看板底部的第五家店“自营公司”，点击后切换自营服装、自营餐饮。

## 上传步骤

1. 在丽晶店铺零售报表中按“单据日期”导出 PBCZ6001 的完整区间，包含销售及退货，不附加商品、会员、销售方式等筛选。
2. 在上传页面填写同一个开始、结束日期，选择 `.xlsx` 文件。
3. 校验并预览明细数、计收额、预计回款、成本及毛利，确认后导入。
4. 在导入记录中核对批次、日期和金额，手机端选择相同日期查看。

导入会在单个数据库事务中替换该店铺、日期区间的明细。重复上传不累加，区间外数据不变。文件不能证明筛选条件是否完整，因此上传者需要核对源系统查询条件。
未导入日期显示未导入；已导入且没有销售的日期可显示零。餐饮未接入前显示等待数据。

## 金额口径

- 销售额：计收额。
- 赠品空值：销售类型为“赠品／赠送”或促销信息含“买满赠送”“会员积分兑换货品”，且计收额、计收价、生意额均为空或零时，空计收额及空计收折扣按零处理，保留商品明细和数量。普通销售缺金额、非数值内容仍报错，明细合计仍须与报表合计一致。有实际收费的换购或积分兑换保留实际金额及折扣。
- 换货：销售方式为“换货”时按正常销售入账，以实际计收额和计收折扣计算，金额和数量应为非负数；保留原始“换货”标记，不计入退货行数。
- 无价格明细：报表具备吊牌价、吊牌额、零售价、生意额、计收价、计收额全部字段，且该行六项均为空或零时，即使没有促销标记，也将空计收额及空计收折扣按零处理，保留明细、数量和原始字段。缺少价格列、任一价格非零或非法时不适用该规则；仍校验折扣、销售方式、数量符号和整表金额合计。
- 甲方成本：按每行计收折扣分档，≥85%乘50%，≥70%且<85%乘52%，<70%乘55%。
- 场地扣款：计收额×15%。
- 预计回款：计收额－场地扣款。
- 毛利：预计回款－甲方成本，尚未扣人工等其他费用。
- 成本和场地扣款每行四舍五入至分，再汇总；退货按负数冲减，采用退货行上的折扣。

## 独立权限

手机端仍需“手机端销售看板”和“查看销售”功能权限。
上传另需“导入自营服装销售”功能权限。
系统管理的数据策略选择资源“自营公司销售（独立范围）”，对应 `self_operated_sales`，动作为 `view`：

- ALL：整个自营公司。
- CUSTOM 的门店范围 `SELF_OPERATED`：整个自营公司。
- CUSTOM 的部门范围 `CLOTHING`：服装；`BAKERY`：餐饮。

可对用户或角色配置，拒绝规则优先。普通用户未配置该独立资源时不可见；不会继承 `business_scope` 的四店范围。管理员按系统现有规则可查看全部。
上传者必须同时具有导入功能和服装数据范围，餐饮权限不能用于导入服装。

## 数据表及初始化

- `self_operated_sales_imports`：文件、校验值、日期范围、导入人和时间、行数及合计。
- `self_operated_sales_lines`：业务字段、结算金额以及原始Excel字段JSON。原始字段可能含会员信息，不通过手机明细接口返回。
- `self_operated_sales_coverage`：已导入的日期，区分缺失数据和零销售。

原始Excel的64列保存在 `source_data` 中，常用查询字段另有类型化列。没有修改原四店销售表，也没有向实体门店表插入会影响合同、楼层的数据。
初始化SQL位于 `deploy/fungkids/self_operated_sales.sql`。命令行初始化并导入：

```bash
python python_app/publish_fungkids_retail.py '/path/店铺零售报表.xlsx' --start 2026-09-01 --end 2026-09-05 --create-tables
```

## 手机端下钻
自营公司展示当日含券销售、当日毛利、财务月含券销售、财务月毛利；选择日期区间时前两项标为本期。板块、单店及小票的销售金额标签统一使用“含券销售”，金额计算不变。门店 PBCZ6001 展示为“购物中心小帆船”。财务月复用百货日期规则，从所选结束日期所在财务月的起始日统计至该结束日期；选本日时截至今天。点击自营公司 → 自营服装／自营餐饮 → 单店汇总 → 小票明细。小票按渠道、日期和单号分组，整张小票分页，保留退货及重复商品行。餐饮沿用 BAKERY 权限编码。

### 手机端财务月折扣结算

点击自营公司、自营服装板块或服装单店的“财务月含券销售”，打开折扣结算弹层。公司入口汇总有权限的自营服装；单店入口限定当前渠道。这三档规则来自服装合同，不应用到自营餐饮。

- 实际成交折扣 ≥85%：我方结算比例50%（甲方50%）。
- 实际成交折扣 ≥70%且 <85%：我方结算比例48%（甲方52%）。
- 实际成交折扣 <70%：我方结算比例45%（甲方55%）。

每档展示含券销售金额、我方结算金额、销售占比，并提供汇总。我方结算金额 `our_settlement`＝含券销售金额－甲方结算金额，甲方结算汇总已有逐笔 `supplier_cost`，保留逐笔四舍五入到分与退货负数冲减；我方结算金额未扣场地、人工等费用，不代表已实际收款。接口保留 `rate`（甲方比例）与 `remittance`（甲方结算金额）供现有调用使用，页面比例按 `1-rate` 展示。销售占比按该档净销售额除以合计净销售额，总额为零时显示“—”。财务月区间跟随已应用的结束日期，数据未导入和部分导入分别提示。接口 `/api/self-operated-sales/discount-settlement` 沿用销售查看权限及自营服装数据范围。
