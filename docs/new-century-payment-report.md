# 新世纪支付方式销售毛利报表

入口：销售分析 → 报表 → 新世纪报表 → 支付方式销售毛利报表。

门店固定为新世纪（603）；默认日期为2026-07-29至2026-08-28（含首尾），支付方式默认0328、0329、0330、0331、0332、0333。支持部门编码、柜组编码、支付方式筛选，页面每页100行，合计和Excel导出包含全部查询结果。

## 统计口径

用户确认严格保留提供的Oracle SQL逻辑。查询运行在柜位系统当前PostgreSQL同步表上，不直接访问Oracle数据库链路。

- 支付金额：`SUM(je * CASE WHEN djlb='1' THEN 1 ELSE -1 END)`。
- 毛利、销售收入：整票`SUM(sgln2)`、`SUM(sglxssr)`按每条支付记录关联累计，不去重、不按支付额分摊，保留源值符号。
- 柜组：小票商品明细的`MAX(gz)`；部门取该柜组的`mfpcode`。
- 保留`payname`作为分组字段，显示名称仍查`paymode.pmname`。因此显示维度相同的多行可能来自不同历史支付名称，不进行二次合并。
- 保留商品明细`rqsj >= 2026-06-01`、销售流水`sgldate >= 2026-01-01`两个固定下限，不随界面日期改变。
- 保留小票头、商品明细汇总、销售流水汇总的内连接；缺失任一关联的数据不计入。
- 折算收入比例使用`ROUND(pmrevrate,4)`，仅展示，不参与金额计算。
- 先筛选目标支付小票，再汇总相关明细，减少无关数据扫描；权限辅助表通过EXISTS限制，不增加汇总行数。
