# 烟花弹幕互动大屏

一个独立的手机 H5 + 现场大屏互动原型：用户扫码进入活动，输入祝福并上滑发射；大屏实时播放烟花和祝福语，并循环展示历史祝福。

大屏采用持续轮播机制：新祝福优先上屏，之后自动回到历史祝福循环，现场始终保持烟花效果。

## 页面

- 大屏：`/display.html?room=lobby`
- 手机：`/join.html?room=lobby`
- 活动后台：`/admin.html?room=lobby`

## 本地运行

```bash
npm install
npm run start
```

浏览器打开：`http://localhost:8787/display.html?room=lobby`

同一局域网内手机扫码前，请通过环境变量设置手机可访问的地址：

```bash
ADMIN_TOKEN=请设置管理员令牌 PUBLIC_BASE_URL=http://你的电脑局域网IP:8787 npm run start
```

活动后台需要输入 `ADMIN_TOKEN`。令牌只保存在当前浏览器会话中，后台接口拒绝未授权访问。

## Docker 独立部署

项目已经提供独立的 `Dockerfile`、`docker-compose.yml`、环境变量示例和 Nginx 配置示例。完整步骤见 [DEPLOY.md](./DEPLOY.md)。

容器通过 `.env` 的 `FIREWORKS_BIND_IP` 控制监听网卡：正式域名部署默认使用 `127.0.0.1` 并通过现有 Nginx/Caddy 接入；内网直连测试可填写服务器内网 IP。它不使用 ShopView 的代码、数据库或 Docker 网络。

部署 ZIP 不包含 `.env`、管理员令牌或活动数据。解压后按 `DEPLOY.md` 从 `.env.example` 生成服务器专用配置与随机管理员令牌。

## 活动后台能力

- 按 `room` 场次保存活动品牌、大屏文案、手机页文案与快捷祝福
- 开启或暂停祝福提交，配置祝福/昵称字数和基础屏蔽词
- 查看祝福数量、手机参与者和大屏在线数
- 保存后通过 WebSocket 实时更新已打开的大屏和手机页面
- 一键清空当前场次祝福，删除前自动生成 SQLite 备份

## 当前安全与稳定性能力

- 单个客户端/IP 30 秒最多提交 3 条
- 祝福语最多 28 字，昵称最多 8 字
- 基础敏感词过滤，所有输出使用纯文本渲染
- SQLite 持久化与 WAL 模式
- WebSocket 心跳、断线重连及大屏播放队列
- 无审核环节，祝福提交后立即上屏

## 正式上线前建议

- 使用 HTTPS/WSS 和固定活动域名
- 使用强管理员令牌并只通过服务器环境变量配置，不写入页面
- 根据活动方词库接入更完整的内容安全审核
- 微信支付版可在 `submit` 消息前增加支付订单校验，校验通过后再允许发射
- 进行 50—200 台手机并发压测，并准备现场备用局域网
- 根据实际 LED 分辨率调整大屏比例、背景主视觉和安全显示区
