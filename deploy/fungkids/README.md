## 数据约定

销售额取计收额，合同档位暂按报表计收折扣判断（85%及以上50%，70%及以上且低于85%为52%，低于70%为55%）。
甲方成本及场地扣款按每行分别四舍五入到分，再汇总；场地扣点为15%。
退货按负数冲减，保留原单号；当前计算依据退货行自身折扣，未做原销售单合同版本追溯。
这是经营试算；合同生效日期、最终结算舍入粒度、折扣字段与合同定义仍需上线前确认。

导入必须声明完整查询日期范围，校验店铺渠道、行数（自动采集时）、金额合计后，在事务中替换指定渠道及区间。
重复明细行可能是两件相同商品，因此保留每一行，不按单号或商品组合随意去重。
空报表不会自动清空数据。手动导入只接受完整、无额外筛选的区间导出；文件本身不能证明筛选完整性。
下载原件留在私有 exports 目录，暂存数据不包含会员姓名、电话、卡号。原件含会员信息，应按业务留存期限清理。

## 服务器预备文件（尚未部署）

`sync_fungkids_retail.py` 是待目标服务器验证的采集实现；本机通过 CUA 操作网页，未运行该 Playwright 程序。
systemd 单元假设部署目录 `/opt/shopview`、运行用户 `shopview`；实际服务器信息未提供，须对应修改。
不使用 Codex 本机定时任务。

部署准备顺序：

1. 在服务器独立虚拟环境 `.venv-fungkids` 安装 `openpyxl==3.1.5` 和经过服务器验证的 Playwright 版本，安装匹配的 Chromium 及系统依赖。
2. 浏览器安装目录设为 `/opt/shopview/fungkids-browsers`，授予运行用户读取及执行权限；创建 `/var/lib/shopview-fungkids` 并交给运行用户。
3. 服务器 `/etc/shopview/fungkids.env` 中设置 `FUNGKIDS_USERNAME` 与 `FUNGKIDS_PASSWORD`，权限 600。不要将实际凭据写入代码、Git 或部署说明。
4. 先以运行用户执行 `python_app/sync_fungkids_retail.py --data-dir /var/lib/shopview-fungkids --once`，必须完成下载、网页条数核对与导入，且退出码为0。
5. 验证普通查询、会话失效后登录以及下一小时执行，再安装并启用本目录 systemd 单元。

状态写入 `status.json`，失败保留既有暂存明细，错误日志不包含密码及网页内容。系统尚未接入失败通知渠道。
